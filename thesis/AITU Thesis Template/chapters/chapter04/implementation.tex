\chapter{Implementation}
\label{chap:implementation}

\section{System Architecture}

Flowmatic is a TypeScript monorepo: NestJS backend (Prisma/PostgreSQL), Vue~3 frontend, Bun/Python inference sidecar, and Docker Compose. Figure~\ref{fig:microservices-topology} shows PostgreSQL, MinIO, RabbitMQ, \texttt{sensor-simulator}, \texttt{model-inference}, Nest backend, and Nginx-served SPA.

\section{Batch Preparation Module}

Clients upload CSV/JSON via \texttt{IngestionController}. Files land in S3-compatible storage; workers parse, score quality, clean, and persist summaries. Export adapters target PostgreSQL, MongoDB, Hugging Face datasets, and flat files. Figure~\ref{fig:batch-upload-pipeline} corresponds to Table~\ref{tab:upload-pipeline-experiment}.

\section{Smart City Module}

Organisation-scoped pipelines use four stages:
\begin{enumerate}
  \item \textbf{Sources} --- HTTP/WebSocket simulators or connectors;
  \item \textbf{Core unit} --- validation, Manual/Auto routing, inference;
  \item \textbf{Lake \& export} --- bronze/silver/gold prefixes on MinIO (Figure~\ref{fig:medallion-lake});
  \item \textbf{Federated demo} --- optional coordinator metadata.
\end{enumerate}

WebSockets stream events to the UI; queue workers handle asynchronous export. Event-driven semantics match ITS practice without mandating a particular message broker.

\section{Model Inference Service}

\texttt{model-inference} loads TorchScript checkpoints from \texttt{models/} or Hugging Face Hub (Table~\ref{tab:production-portfolio}). Requests specify checkpoint id, feature window $L{=}48$, and task tensors (e.g.\ $\mathbf{A}$ for STGCN). Latency benchmarks appear in Section~\ref{sec:ablations}.

\section{Research Artifact Pipeline}

Training lives under \texttt{models/}: \texttt{run\_phase2\_prep.py} builds datasets; \texttt{run\_phase3\_core.py} runs the multi-seed suite, streaming benchmarks, and Hub upload. Each checkpoint ships \texttt{metadata.json}, scaler statistics, metrics JSON, and TorchScript exports.
