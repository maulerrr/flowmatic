\section{Platform Evolution (Flowmatic)}

Following the classical preparation study, the research was extended into \textbf{Flowmatic}---a production platform that preserves the five preparation stages while adding (i)~organisation-scoped smart-city pipelines, (ii)~an adaptive core unit with Manual/Auto model routing, (iii)~a reproducible eight-model neural portfolio, and (iv)~public Hugging Face artifacts. Chapters~\ref{chap:methodology}--\ref{chap:results} report both the original tabular protocol and the platform/neural evaluation aligned with this repository.

\section{Updated Research Objectives (Platform Phase)}

The platform phase adds:
\begin{enumerate}
  \item To operationalise preparation and inference as containerised services with auditable run metadata.
  \item To define a modality-safe model registry and routing policy for heterogeneous urban telemetry.
  \item To benchmark neural specialists under held-out temporal test splits with multi-seed replication.
  \item To validate the system through reproducible API experiments and a live Astana smart-city demo.
\end{enumerate}
