\chapter{Abstract}
\begin{SingleSpace}
Urban transportation systems produce heterogeneous traffic and sensor data that must be cleaned, validated, and prepared before analysis. This thesis presents \textbf{Flowmatic}, a deployable platform for batch uploads and smart-city pipelines on a \emph{semi-synthetic Astana} case study, and documents how it extends an earlier offline preparation study.

\textbf{Scientifically,} an eight-checkpoint neural portfolio (forecasting, anomaly reconstruction, imputation, graph traffic, severity classification) is evaluated on held-out temporal test splits with three random seeds; the severity classifier reaches macro-F1 = $0.911 \pm 0.017$. Weights and scripts are published on Hugging Face (\texttt{@pushthetempo/flowmatic-*}).

\textbf{Engineering-wise,} Flowmatic implements preparation as a NestJS/Vue Docker stack: batch uploads pass quality checks and cleaning workers (30\,000 records in 406\,ms, score 100/100), and a smart-city workbench connects an Astana geospatial simulator with Manual/Auto registry routing and medallion lake export.

An archival June 2025 memoir pilot (offline Python, XGBoost tabular classification) motivated the preparation methodology but is \emph{not} re-run in this repository and is \emph{not} deployed in production inference. The dissertation connects that pilot to the reproducible platform and documents where evidence diverges between the two tracks.

\end{SingleSpace}
\keywords{Data Preparation, Intelligent Transportation Systems, Smart Cities, Model Routing, Time Series, Anomaly Detection, Flowmatic}
